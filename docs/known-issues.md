# 已知问题与 V1 建议

## V0 已知问题

- 当前工作区目录列表按文件索引推导，不提供独立的文件夹树管理器。
- 文件扫描和 SHA-256 计算位于 Main 的异步任务中；极大文件较多时首次扫描时间取决于磁盘性能。
- Windows 安装包需要在完整安装 Electron 和原生依赖后手动生成。
- V0 不尝试合并两个冲突画布，只保留原文件和冲突副本。
- 工作区首页每页显示 60 个画布，最近打开最多 20 个。

## V1 S3 / OSS / MinIO

建议继续复用 `StorageProvider`，新增统一 `S3StorageProvider`：

- OSS、MinIO、通用 S3 只作为配置预设
- 编辑器始终先写本地缓存
- 上传进入持久化同步队列
- 使用 ETag 做远端版本检测
- 网络错误指数退避，支持取消和手动重试
- 凭证交给系统安全存储，不进入 SQLite 和日志
- 远程重命名使用 CopyObject + DeleteObject
- 本地有未上传修改且远端 ETag 改变时生成两个独立版本

不要采用默认“最后写入者获胜”，也不要让编辑器等待远程请求完成。
