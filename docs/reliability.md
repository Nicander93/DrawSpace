# 自动保存、冲突与恢复

## 自动保存

Excalidraw `onChange` 只更新 Renderer 内存状态。停止操作 800ms 后调用 Main 保存。以下事件会立即尝试保存：

- `Ctrl + S`
- 窗口失焦
- 返回工作区
- 关闭应用

关闭应用时 Main 会先发送关闭请求，最多等待 5 秒。编辑器完成保存或写入恢复快照后再确认关闭。

## 外部修改

打开画布时记录：

- mtime
- 文件大小
- SHA-256

保存前重新读取并比较三项。如果外部文件发生变化，原文件不会被覆盖。当前编辑内容会保存为：

```text
原名称 (冲突副本 日期时间).excalidraw
```

编辑器随后打开冲突副本。V0 不做元素级自动合并。

## 恢复快照

持续编辑时每 10 秒写入：

```text
userData/recovery/<documentId>.json
```

保存失败和关闭前无法保存时也会写入快照。启动时只有同时满足以下条件才提示：

- 快照晚于正式文件
- 对应编辑会话未正常结束
- 快照可以解析

恢复始终创建副本，不静默覆盖正式文件。用户也可以查看摘要、暂时忽略或删除快照。

## 缩略图

保存成功后 Renderer 使用 Excalidraw 官方导出能力生成最大 480×270 PNG，Main 将其写入 `userData/thumbnails`。缩略图失败不会使画布保存失败。
