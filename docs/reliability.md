# 自动保存、冲突与恢复

## 自动保存

Excalidraw `onChange` 只更新 Renderer 内存状态。保存由每个文档独立的 `DocumentSaveCoordinator` 串行排空：停止操作 5 秒后保存，持续编辑最长 30 秒触发一次保存。保存期间继续编辑会进入下一轮，不会并发写入同一正文。以下事件会进入同一保存队列：

- `Ctrl + S`
- 返回工作区
- 切换或关闭标签
- 关闭应用

关闭应用时 Main 会先发送可取消的关闭请求。Renderer 会列出未保存标签，用户可以全部保存、放弃修改或取消退出；取消时不会释放工作区服务。

关闭请求携带唯一 `requestId`，Main 只接受当前请求的 `proceed/cancel` 响应；重复关闭和过期响应都会被忽略。自动保存不依赖窗口 `blur`，避免失焦时产生额外并发写入。

## 外部修改

打开画布时记录：

- 文件版本
- 文件大小
- SHA-256 正文哈希

保存前重新读取并比较正文哈希，并在 Provider 写入时再次校验版本。如果外部文件发生变化，原文件不会被覆盖。当前编辑内容会保存为：

```text
原名称 (冲突副本 日期时间).excalidraw
```

编辑器随后打开冲突副本。V0 不做元素级自动合并。

## 恢复快照

持续编辑时每 10 秒写入：

```text
userData/recovery/<documentId>.json
```

保存失败和关闭前无法保存时也会写入快照。启动时只有同时满足以下条件才提示：

- 快照晚于正式文件
- 对应编辑会话未正常结束
- 快照可以解析

恢复始终创建副本，不静默覆盖正式文件。用户也可以查看摘要、暂时忽略或删除快照。

## 缩略图

保存成功后 Renderer 使用 Excalidraw 官方导出能力生成最大 480×270 PNG，Main 将其写入 `userData/thumbnails`。缩略图失败不会使画布保存失败。
